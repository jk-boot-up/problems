# 342. Power of Four

**Difficulty:** Easy &nbsp;|&nbsp; **Topic:** Bit Manipulation &nbsp;|&nbsp; [LeetCode](https://leetcode.com/problems/power-of-four/)

## Problem

Return `true` if `n` is a power of four.

**Example**
```
16 → true
5  → false
1  → true
```

**Constraints**
* `-2^31 <= n <= 2^31 - 1`
