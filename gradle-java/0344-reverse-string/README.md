# 344. Reverse String

**Difficulty:** Easy &nbsp;|&nbsp; **Topic:** Two Pointers &nbsp;|&nbsp; [LeetCode](https://leetcode.com/problems/reverse-string/)

## Problem

Reverse an array of characters `s` **in place** with O(1) extra memory.

**Example**
```
["h","e","l","l","o"] → ["o","l","l","e","h"]
```

**Constraints**
* `1 <= s.length <= 10^5`
