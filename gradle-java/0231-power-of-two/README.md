# 231. Power of Two

**Difficulty:** Easy &nbsp;|&nbsp; **Topic:** Bit Manipulation &nbsp;|&nbsp; [LeetCode](https://leetcode.com/problems/power-of-two/)

## Problem

Return `true` if `n` is a power of two, that is `n == 2^x` for some integer `x >= 0`.

**Example**
```
1  → true   (2^0)
16 → true
3  → false
```

**Constraints**
* `-2^31 <= n <= 2^31 - 1`
