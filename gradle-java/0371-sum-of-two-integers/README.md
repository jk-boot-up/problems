# 371. Sum of Two Integers

**Difficulty:** Medium &nbsp;|&nbsp; **Topic:** Bit Manipulation &nbsp;|&nbsp; [LeetCode](https://leetcode.com/problems/sum-of-two-integers/)

## Problem

Return `a + b` without using the `+` or `-` operators.

**Example**
```
1 + 2 = 3,   2 + 3 = 5,   -1 + 1 = 0
```

**Constraints**
* `-1000 <= a, b <= 1000`
