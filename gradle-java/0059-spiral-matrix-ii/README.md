# 59. Spiral Matrix II

**Difficulty:** Medium &nbsp;|&nbsp; **Topic:** Matrix &nbsp;|&nbsp; [LeetCode](https://leetcode.com/problems/spiral-matrix-ii/)

## Problem

Generate an `n × n` matrix filled with `1 .. n²` in clockwise spiral order.

**Example**
```
n = 3 → [[1,2,3],[8,9,4],[7,6,5]]
```

**Constraints**
* `1 <= n <= 20`
